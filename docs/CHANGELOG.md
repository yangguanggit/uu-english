## [1.0.0] - 2026-10-22

初始版本基线，包含截至本次初始化已实现的功能与修复。此记录不代表已部署上线。

### 学习内容与儿童端

- 提供今天、探索、分级书架三个底部入口，以及搜索、收藏、最近学过、奖励与复习。
- 基础学习包含 26 个字母、24 个入门音标、40 类 500 个常用单词及对应自然拼读；拼读分级路线精选 100 个示例词。
- 句型积木包含 10 类、每类 10 句，共 100 句；支持替换表达、角色互换与亲子陪练。
- 提供 50 类场景、250 个小游戏、500 条分支，每站三轮交流；场景模拟最多随机组合五站。
- 提供 100 本原创绘本，10 级、每级 10 本，共 600 页；支持听故事、跟读、自己读、沉浸阅读、左右滑动翻页及阅读互动。
- 提供 50 条主题路线，串联单词、场景、绘本与次日复习。
- 顶部导航固定，二级页面统一返回；刷新恢复页面位置，分类栏单行展示数量并支持内容区横滑切换。
- 适配手机、平板和桌面；单词卡片按宽度调整列数，避免长单词从中间拆行。

### 音色与播放

- 保留成人音色，默认儿童音色；偏好按孩子保存，支持扩展音色包。
- 支持慢速 `0.50×`、正常 `0.75×`、快速 `1.00×`，默认正常；绘本沿用全局语速，连续朗读页间停顿一秒。
- 字母只读字母名称，单词依次朗读英文与中文；基础学习与场景支持自动播放和手动重播。
- 音标及自然拼读单音共用标准真人示范；录音仅在页面临时回听，浏览器识别不作为发音评分。
- 普通语音直接维护 64 kbps MP3，字母及标准单音保留原始 WAV；原始录音归档在项目外，打包不重复转码。
- 音频按音色和功能模块分类，同音色相同字节共用；正式实体音频共 10,935 个，逻辑教材 ID 保持稳定。
- 音色导入支持 WAV 一次编码、MP3 原样复用、解码时长校验、制作清单同步和失败回滚；候选生成拒绝截断或静音文件。

### 家长空间与进度

- 提供陪练与成长、孩子与设置、离线学习三个底部入口；设置采用分组与二级页，音色位于语速上方。
- 支持学习计划、起点建议、休息提醒、成长报告、内容审校及版本检查。
- 支持多孩子档案、切换、改名、确认删除、备份恢复及多标签页同步；进度保存在浏览器，按孩子隔离，无服务端账号或跨设备云同步。
- 学习日志支持检查点和并发保护；备份导入、导出统一限制为 64 MiB，清除记录保留其他孩子及共享离线包。
- 审校支持问题标记、批准拦截和内容变化后重审；家长空间刷新后重新验证。
- 自定义下拉框统一外观、键盘交互与关联标签名称。

### 离线、部署与安全

- 支持双音色主题包下载、校验、更新、失败重试、删除及残留清理；共享媒体与孩子进度分别管理。
- 离线媒体保留 MP3/WAV MIME 与 Range 响应；支持更新检测、更新前备份和设备检查。
- 提供 `dist/` 静态发布构建、Nginx vhost、部署验收与回滚说明，无需自建应用镜像或 Python 服务。
- 发布目录统一为 0755、文件为 0644；构建校验输入与输出路径、拒绝符号链接和非构建目录，发布失败恢复旧包，恢复异常保留备份路径。
- 可选 Python 页面服务监听 `0.0.0.0:8080`，仅开放登记资源，禁止目录浏览、隐藏文件、未登记文件和符号链接。
- 诊断独立监听，默认 `127.0.0.1:8081`；页面端口拒绝诊断写入，诊断按实际连接来源限制内网访问。
- 提供连接限额、超时、限流、日志轮转及跨源嵌入限制；音色导入逐层检查目标路径并校验媒体摘要。
