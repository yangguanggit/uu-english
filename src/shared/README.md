# 共享工具

两端共用的导航、音频、存储和学习逻辑。普通脚本通过 `window.Bear*` 暴露接口，依赖顺序由 `index.html` 声明。

| 路径 | 职责 |
| --- | --- |
| navigation.js | 返回栈、页面恢复、儿童底部导航、家长验证 |
| audio/player.js | 播放队列、取消、超时、事件；调用方回调处理学习证据 |
| audio/microphone.js | 麦克风授权、识别、临时录音、回听与释放 |
| audio/playback.js | 全局语速及保留音高处理 |
| audio/voices.js、voice-packs.js | 音色解析、注册和媒体映射 |
| storage/profiles.js | 档案命名空间、备份校验与导入导出 |
| storage/learning-state.js | 逐事件合并的学习记录、阅读、计划、收藏与设置 |
| storage/practice-drafts.js | 练习草稿保存、草稿及审校备份字段校验 |
| storage/offline.js | 离线清单、下载、缓存、哈希验证与删除 |
| learning/curriculum.js、learning-tools.js | 课程关联、搜索、复习、足迹与周报 |
| learning/growth.js、progression.js | 证据分层、题库、听完门禁、分支与跨情境练习 |
| learning/roleplay.js、sentences.js | 角色轮次、关联场景的练习音频资源 |
| learning/session.js | 可见且最近一分钟有操作时的近似活跃计时与休息提醒 |
| content/review.js | 人工审校状态、内容指纹及重审判定 |
| ui/ | page-layout.js 组合吸顶分类栏并测量高度；下拉框、语义配图、内容更新提示；category-rail.js 统一分类数量标签（单项省略）、单行导航、点击／内容区横滑切换、嵌套分类隔离、监听清理与防误触；styles/tabs.css 统一主／子级分类样式 |

## 音频约定

默认儿童音色；已主动选择的音色继续保留。无选择记录的旧成人默认值迁移为儿童，旧备份保留已保存音色；设备缺少所选音色时提示并暂用成人，保留原选择。切换音色会停止播放。

语速为慢速 **0.50×**、正常 **0.75×**、快速 **1.00×**，默认正常。音标、自然拼读单音共享标准真人录音。原始练习录音仅在页面内存中，正式环境的麦克风和离线能力需 HTTPS。

媒体统一通过 `BearVoices.resolve(逻辑 ID, 音色)` 解析，不拼接物理目录；`BearVoices.has` 用于筛除不存在的可选旧慢速录音。字母／单词／场景／绘本等按模块存放，同音色重复字节共用，播放器保留每个逻辑引用的语速。

审校试听使用 `BearLesson.playFile(file,label,voiceId,{recordLearning:false})`，不修改孩子偏好或听过记录。媒体维护见[音频说明](../../audio/README.md)。

## 存储与扩展

数据位置统一见[项目说明](../../README.md#数据与进度)。学习记录采用按孩子隔离的事件日志；支持 Web Locks 的安全上下文中，累计 256 条事件后自动合并检查点，仅删除已合并事件。检查点包含事件 ID、覆盖字段的版本顺序，以及最近重置后的成功练习顺序；延迟补写会重算连续选对次数与复习日期，重置前的顺序明细会移除。旧检查点缺失的顺序无法还原，按其已保存结果作为基线保护。写入后中断删除也不会重复计数；存储恢复后补写的旧音色、设置、阅读位置及练习草稿不能覆盖新值，累计次数仍合并。旧格式检查点按已捕获的最新事件保护状态；不支持 Web Locks 时保留事件，避免并发丢失。清除先切换日志代次，再移除旧日志及迁移副本，其他标签页未保存的旧事件不能重新写回；清除失败须向家长提示。

`growth.lab` 保存句型及角色草稿，`growth.reviews` 保存审校台账，`growth.practice` 保存轮换及跨情境记录；绘本活动在 `reading[id].interactions`。新增状态须同步备份校验及清除语义；覆盖字段须登记检查点字段版本，累计或集合字段按合并语义处理。

备份统一采用 UTF-8 字节上限 64 MiB，导入预检与解析使用同一校验；两个下载入口通过 `BearProfiles.backupText()` 输出紧凑 JSON 并检查大小。此上限为文件处理保护，不代表浏览器本地存储容量；空间不足会回滚恢复并保留原档案。

`progression.js` 的 `registerSceneResources(provider)` 合并扩展文本和音频；句型、角色模块通过它参与离线包，不覆盖 `sceneTexts`／`sceneFiles`。提供方须先于应用入口加载。

共享逻辑不反向引入两端页面；修改公共接口前检查全部调用方。保留存储 key、事件含义和根路径 `sw.js`。离线可用性须核验 revision 和文件哈希，不能只凭下载记录；失败包仍须能更新或移除。

接触、跟读、识别与独立选对是不同证据，不将次数或练习尝试描述成发音评分。审校默认待审，内容与引用音频变化后需重审。相关验证见[测试说明](../../tests/README.md)。

档案增删、改名、切换和恢复返回 Promise，调用方须等待完成再刷新页面。通过 Web Locks（缺失时使用 IndexedDB 读写事务）串行执行，并在锁内读取最新索引、复核档案上限与目标是否存在；改名始终针对本页面打开的孩子。档案锁数据库 `bear-profile-locks` 只提供互斥，不存昵称或学习记录。

跨情境证据按单词、日期与情境写入增量事件，轮换记录按小游戏独立保存；不要提交整个旧练习对象。每日任务开始时保存 `BearLearning.taskContext()`，完成时传入 `task(key, context)`，刷新和返回恢复也须保留该上下文；旧会话缺失上下文时仅保留学习记录，不完成当前计划。

离线包下载、删除与共享媒体清理在同一 Web Lock 内串行执行，完成标记发布前验证媒体与页面完整性。锁跨页面、孩子及应用版本共用；缺少 Web Locks 时拒绝变更缓存并提示更新浏览器，已下载资源仍可校验和使用。

收藏写入明确的目标状态，以资源为单位保留事件版本；其他页面同步刷新收藏按钮和收藏列表。旧日志中的 toggle 仍按原含义读取，新增调用优先传 `favorite(key, chosen)`，按钮以点击前的展示状态确定意图。

离线下载在写入素材前保存 `__offline_pending__/主题ID` 恢复清单，失败或刷新后仍可重试和删除；新包验证通过后才更新完成标记并移除恢复清单。更新失败不提前删除旧完成标记，是否可用仍由哈希校验决定。清理只移除未被其他完整包或未完成包引用的媒体，兼顾旧版无标记残留；删除清理成功前保留清单，失败可再次操作。

家长端「存储与空间 → 清理残留音频」通过 `BearOffline.cleanup()` 回收旧版没有主题记录的遗留音频；同样使用离线全局锁，并保留主题清单引用的素材和全部学习进度。
