# 家长端

经 `BearNavigation` 验证进入；该验证用于减少孩子误入，不是账号认证。三个底部 tab 首页只展示摘要和入口，二级页使用共享返回箭头；刷新后重新验证并恢复目标页面。

| Tab | 内容 |
| --- | --- |
| 陪练与成长 | 随机场景陪练、成长报告、待巩固内容、亲子小游戏 |
| 孩子与设置 | 学习计划、音色语速、起点与休息、档案、备份、内容审校、版本检查 |
| 离线学习 | 主题包搜索、下载、更新、移除与存储空间 |

## 管理规则

档案和进度仅存当前浏览器，离线包由所有孩子共享。备份导出采用紧凑 JSON；导出、导入统一校验 UTF-8 大小（最多 64 MiB），恢复仍受目标浏览器本地容量限制。删除须二次确认；删除最后一个档案后创建空白档案。恢复默认新增档案，满额备份可替换未使用的默认档案，不能覆盖已有学习记录。

音色选项在语速上方，默认儿童音色；偏好按孩子保存并随备份恢复。清除学习记录会恢复该孩子的默认偏好。下载任务独立于页面，切换 tab 后继续回传结果；只有校验通过的包才可离线进入。

审校按资源、页码与类型记录待审／已审／需修正。有未处理问题不能批准，内容变化后需重审；试听不改变音色偏好或增加学习证据。更新检查必须确认备份已保存后才刷新，麦克风检查结束立即释放输入。

清除学习记录会删除当前孩子的历史事件及迁移副本，并恢复偏好默认值；其他孩子与共享离线包保留。存储权限阻止清除时显示错误并保留当前页面，不自动刷新。

数据位置见[项目说明](../../README.md#数据与进度)，回归入口见[测试说明](../../tests/README.md)。
